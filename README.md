SHK Theorie Trainer V113

Änderung:
- Nach dem Beantworten von Fragen gibt es eine kurze fachliche Erklärung.
- Die Rückmeldung lautet nicht mehr nur „Richtig/Falsch“ mit „Richtige Antwort“.
- Bei falscher Antwort wird zusätzlich die passende Lösung genannt, damit der Zusammenhang verständlich bleibt.
- Prüfung ohne Direktfeedback bleibt unverändert; die Prüfungslösungen werden erst am Ende angezeigt.
